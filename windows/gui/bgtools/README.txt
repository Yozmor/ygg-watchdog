Фон-древо для окон ygg-watchdog и панели Yggdrasil
bg_gray.png  — серый, 1560x960: ветви на тёмном, без панелей, текста и рамок. Окно красит его в цвет темы.
bg_green.png — зелёный вариант для сторожа.
bg_ice.png   — голубой вариант для панели Yggdrasil (с ветвью переднего плана слева внизу).
make_bg.py + bigtree.py — скрипт, которым фон нарисован: python make_bg.py [ширина высота]. Нужны Pillow, numpy, scipy.
В начале make_bg.py: SEED (форма дерева), TRUNK_X (где ствол), DIM_* (яркость).
