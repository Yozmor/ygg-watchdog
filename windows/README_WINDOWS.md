# Yggdrasil Watchdog (Windows) - инструкция

## Что это

То же самое, что и Linux-версия, но полностью на C++ (без Python -
на этой машине Python доступен только через Windows Store алиасы,
которые несовместимы с Планировщиком заданий). Один `.exe`, никаких
внешних зависимостей кроме стандартных библиотек Windows.

## Что работает автоматически, без твоего участия

Раз в 3 минуты Планировщик заданий запускает проверку (`tick`) от
имени `SYSTEM` - работает независимо от того, вошёл ли ты в систему,
и не показывает никаких окон (сессия 0, изолированная от рабочего
стола):

- Если все основные пиры легли - ищет замену того же региона, что
  основные, проверяет настоящим рукопожатием, добавляет как резервного
- Как только основной снова жив - резервные убираются
- Если включён региональный режим - следит за региональными пирами
  вместо основных
- Если пропал интернет вообще - не тратит время на бессмысленный
  поиск, ждёт восстановления
- Задача сама настроена срабатывать сразу при пробуждении из сна,
  если пропустила тик во время сна (`StartWhenAvailable`)

Проверить, что задача жива:
```
schtasks /Query /TN "YggWatchdogTick" /V /FO LIST
```
Ищи `Scheduled Task State: Enabled` и `Status: Ready`.

## Файлы проекта - должны лежать вместе, в одной папке

| Файл | Назначение |
|---|---|
| `ygg_watchdog.cpp` | Исходник - вся логика |
| `cities.dat` | База городов GeoNames с координатами (обязателен) |
| `notify.conf` | Токен/chat_id для уведомлений в Telegram (необязателен - без него уведомления просто выключены) |
| `run_ygg_watchdog.bat` | Собирает `.exe` из исходника (если нужно) и запускает |
| `app.rc`, `ygg-watchdog.ico` | Иконка программы, вшивается в `.exe` при сборке |
| `ygg_watchdog.exe` | Готовая программа (или появится после сборки батником) |
| `watchdog.log` | Лог - появится после первого запуска |
| `state.txt` | Файл состояния - появится после первого запуска |

## Установка

Скачай из этой папки `ygg_watchdog.exe`, `cities.dat` и `notify.conf.example`, положи их в одну постоянную папку (например `C:\Tools\ygg-watchdog`), дважды кликни `ygg_watchdog.exe` и в меню выбери пункт **2**, чтобы установить задачу планировщика.

Не переноси папку после установки задачи: планировщик запоминает путь к exe. Если перенёс, снова выбери пункт 2.

## Сборка из исходника / пересборка после обновления

```
run_ygg_watchdog.bat
```

Если `.exe` не существует или исходник (`ygg_watchdog.cpp`) новее уже
собранного `.exe` - соберёт заново сам (ищет `g++`, потом `cl`, потом
пытается найти Visual Studio автоматически). После пересборки
**обязательно** зайди в меню и выбери пункт 2, чтобы переустановить
задачу планировщика - без этого Планировщик продолжит использовать
дату/настройки старой версии задачи.

## Меню

Двойной клик по `ygg_watchdog.exe` (или по `run_ygg_watchdog.bat`)
открывает меню:

```
================================================
        YGG WATCHDOG
================================================

  1 - Проверить сейчас (tick)
  2 - Установить задачу планировщика (install-task)
  3 - Добавить регион (страна + город)
  4 - Убрать региональный режим
  5 - Показать основные пиры
  6 - Добавить основной пир
  7 - Удалить основной пир
  8 - Перезапустить Yggdrasil СЕЙЧАС (обрывает сессии по Yggdrasil!)
  9 - Перезапустить Yggdrasil С ЗАДЕРЖКОЙ (безопасно при RDP по Yggdrasil)
  0 - Выход
```

При первом запуске каждой команды спросит права администратора через
UAC - это ожидаемо (нужны для доступа к `yggdrasilctl` и Планировщику).

### Пункт 1 - Проверить сейчас
То же самое, что делает Планировщик каждые 3 минуты, но сразу.

### Пункт 2 - Установить задачу планировщика
Нужно вызвать один раз при первой установке, и повторно - после
каждой пересборки `.exe` (см. выше).

### Пункт 3 - Добавить регион
1. Покажет список стран (живой, с GitHub) - вводишь номер
2. Покажет список городов этой страны (из базы GeoNames с реальными
   координатами) - вводишь номер, или Enter для пира из любого города
3. Запустит поиск **в фоне** (отдельный процесс) - меню сразу
   возвращает управление. Настоящая проверка (рукопожатие) может
   занять от нескольких секунд до пары минут.

Пока региональный режим активен - основные пиры полностью
игнорируются (осознанное правило). Можно вызывать пункт 3 несколько
раз подряд для нескольких регионов сразу - предыдущие не потеряются.

### Пункт 4 - Убрать региональный режим
Снимает все региональные пиры разом, возвращает обычный режим.

### Пункты 5-7 - Основные пиры
- **5**: список из `yggdrasil.conf`
- **6**: добавляет URI прямо в конфиг (спросит адрес)
- **7**: покажет список, спросит номер для удаления

**Правки вступают в силу только после перезапуска службы** (пункты 8/9).

### Пункты 8-9 - Перезапуск службы Yggdrasil
- **8** - сразу. Если подключён к этому компьютеру через сам
  Yggdrasil (например RDP по Yggdrasil-адресу) - соединение оборвётся
  в процессе.
- **9** - с задержкой (по умолчанию 10 секунд). Команда уходит по ещё
  живому каналу, перезапуск происходит через несколько секунд -
  успеваешь отключиться/переключиться заранее.

**Используй пункт 9, если не уверен, как именно сейчас подключён.**

## Уведомления в Telegram

Программа умеет присылать push-уведомления в Telegram на телефон в
трёх случаях:

- **Все основные пиры легли, найден резервный** - в сообщении будет
  указано, какие именно основные пиры отвалились, и какой резервный
  добавлен взамен
- **Основные пиры снова живы** - какие резервные удалены
- **Пропадал интернет целиком** (не только Yggdrasil) - одно
  сообщение с обоими точными временами: когда пропал и когда появился

Рутинные проверки ("всё в порядке, без изменений") в Telegram **не**
шлются - только реальные события, чтобы не спамить.

### Настройка (один раз)

1. Открой `@BotFather` в Telegram, отправь `/newbot`, следуй
   инструкциям - получишь токен вида `123456:ABC-DEF...`
2. Напиши что-нибудь своему новому боту (любое сообщение)
3. Открой в браузере:
   `https://api.telegram.org/bot<ТВОЙ_ТОКЕН>/getUpdates`
4. В ответе найди число в поле `"chat":{"id": ЭТО_ЧИСЛО}`
5. Переименуй `notify.conf.example` в `notify.conf` (та же папка, что
   `ygg_watchdog.exe`), впиши токен и chat_id:
   ```
   BOT_TOKEN=123456:ABC-DEF...
   CHAT_ID=987654321
   ```

Если файла `notify.conf` нет вообще, или в нём не хватает одного из
полей - уведомления просто молча выключены, ничего не ломается и не
падает с ошибкой.

**Если у тебя два устройства (например Windows-ноутбук и Linux-сервер
Kjele) шлют уведомления в одного и того же бота** - в каждом сообщении
автоматически указывается имя устройства-отправителя (реальное имя
компьютера), чтобы не путать, откуда пришло.

## Логи

Файл `watchdog.log` рядом с `.exe`. По умолчанию видны только
осмысленные события (что произошло на каждой проверке, не только
аномалии). Для подробностей:
```
ygg_watchdog.exe -v tick
```
Логи старше 14 дней подчищаются автоматически.

## Проверка, что служба Yggdrasil тоже настроена на автозапуск

Это отдельная от watchdog служба - ставит её сам установщик Yggdrasil:
```
sc qc Yggdrasil
```
Ищи `START_TYPE: 2 AUTO_START`.

## Известные технические детали (на случай если пригодится позже)

- Задача Планировщика зарегистрирована от `SYSTEM` - специально, чтобы
  не зависеть от входа в систему и не показывать окно на рабочем столе
  (сессия 0)
- Файл состояния (`state.txt`) - простой текстовый формат `ключ=значение`,
  не JSON - читается построчно, при парсинге аккуратно обрезается
  завершающий `\r` (важно: раньше без этого в списке резервных пиров
  мог появляться "призрачный" пустой пир после каждой попытки очистки)
- `AdminListen` в `yggdrasil.conf` должен быть на отдельном порту
  (`tcp://127.0.0.1:9002`), не на дефолтном 9001 - иначе `yggdrasilctl`
  может случайно достучаться не туда при резолвинге `localhost` в IPv6

## Команда напрямую (без меню)

```
ygg_watchdog.exe tick
ygg_watchdog.exe install-task
ygg_watchdog.exe add-region <номер_или_slug> <номер_или_город>
ygg_watchdog.exe remove-region
ygg_watchdog.exe list-countries
ygg_watchdog.exe list-cities <страна>
ygg_watchdog.exe list-main-peers
ygg_watchdog.exe add-main-peer tls://host:port
ygg_watchdog.exe remove-main-peer 2
ygg_watchdog.exe restart-yggdrasil
ygg_watchdog.exe restart-yggdrasil-delayed 15
```
