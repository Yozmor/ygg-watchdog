<h1 align="center">ygg-watchdog</h1>

Программа для [Yggdrasil](https://yggdrasil-network.github.io/): следит за связью, сама восстанавливает её, когда что-то идёт не так, и сообщает о сбоях в Telegram. Есть версии для Windows (C++, окно, значок в трее, Планировщик заданий) и Linux (Python + systemd).

## Быстрый старт

- **Windows:** скачай из папки [`windows`](windows) файлы `ygg_watchdog.exe`, `ygg_guard.exe`, `cities.dat` и `notify.conf.example` и положи их в одну папку. Дважды кликни `ygg_watchdog.exe` и в окне на вкладке «Управление» нажми «Установить».
- **Linux:** выполни 6 команд из раздела [Установка → Linux](#linux), программа встанет в `~/ygg-watchdog`.

## Что делает

Ниже описана Windows-версия. Linux-версия пока работает по прежней логике, отличия перечислены [в конце раздела](#linux-версия-сейчас).

Каждые 3 минуты программа проверяет связь и действует сама:

- **Держит от 3 до 7 живых пиров.** Основные пиры (из `yggdrasil.conf`) она не трогает никогда. Если живых меньше трёх, добирает резервные в той же проверке. Если больше семи, убирает лишние резервные, начиная с самой большой задержки.
- **Пир «подключён», но постоянно рвётся.** Если пир переподключился 3 раза за полчаса, он не считается живым: формально он Up, но трафик через него не идёт. Ему ищется замена.
- **Где искать замену.** По очереди, без повторов одной страны:
  1. страна, откуда реально выходит трафик (по GeoIP, так учитывается VPN);
  2. регион поездки;
  3. домашний регион;
  4. страна основных пиров.

  Внутри страны первыми идут пиры, ближайшие к выбранному городу (по координатам из базы GeoNames), и те, что раньше работали надёжно. Сначала быстрая проба портов, потом настоящее рукопожатие только с теми, кто ответил.
- **Обычный поиск не помог и живых пиров нет совсем** — включается крайний перебор: все пиры всех стран из публичного списка. Перебор ограничен по времени одной проверки и продолжается в следующей с того же места. После полного прохода без результата — пауза 12 часов.
- **Служба Yggdrasil остановлена.** Если у неё тип запуска «Автоматически», программа запускает её и сообщает. Если «Вручную» или «Отключена», считает, что её остановили намеренно: только сообщает.
- **Сломался `yggdrasil.conf`** (например, ошибка при ручной правке). Программа хранит рабочую копию конфига и предлагает вернуть её кнопкой в окне. Заменяет только после подтверждения, битый файл сохраняется рядом.
- **Сетевой адаптер Yggdrasil не создан, выключен или без маршрута 200::/7.** Пиры могут быть живы, а трафик всё равно не идёт. Программа это замечает и сообщает.
- **Пропал интернет целиком.** Программа не тратит время на поиск пиров, ждёт и потом присылает одно сообщение с точным временем пропажи и возврата.
- **Своё устройство недоступно.** Если связь в порядке, а добавленный вручную компьютер не отвечает, программа проверяет, не мешает ли нагрузка самому Yggdrasil на этой машине. Если мешает, перезапускает службу.
- **Критический заряд батареи** (≤5%, не на зарядке) — все проверки на паузе до зарядки. Одно сообщение на вход и одно на выход.
- **Целостность самой программы.** Задача Планировщика запускает маленького стража `ygg_guard.exe`. Если `ygg_watchdog.exe` повреждён или пропал, страж скачивает целый файл из этого репозитория и сверяет его отпечаток. Сторож, в свою очередь, следит за стражем.
- **Автопроверки замолчали** (задачу удалили или выключили) — значок в трее присылает сообщение в Telegram и на экран и предлагает восстановить задачу. Восстанавливает только после подтверждения.
- **Статистика.** Для каждого пира копятся доступность, средняя задержка, P95 и разброс за 1 час, сутки и неделю, а также надёжность за 30 суток. Её видно на вкладке «Статистика», можно выгрузить в CSV.
- **Фаервол и антивирус** программа не трогает. Перед крайним перебором она только читает правила фаервола и предупреждает, если похоже на блокировку.
- **VPN.** По умолчанию программа в VPN-клиент не лезет. Можно один раз одобрить свой скрипт перезапуска VPN. Перед каждым запуском программа сверяет его SHA-256 и отказывается запускать, если скрипт изменился хоть на байт.
- **Обновления.** Раз в сутки программа сравнивает свою версию с версией в репозитории и только сообщает. Ставится обновление кнопкой в окне.

Для ручного управления есть окно с вкладками: обзор, пиры, каталог публичных пиров, статистика, регион, устройства, журнал, управление. Всё доступно и с клавиатуры (Tab, стрелки, Enter). Есть также значок в трее со своими всплывающими окнами.

**Уведомления в Telegram** (необязательно) — только о значимых событиях: связь пропала или вернулась, добавлены резервные, пропадал интернет, устройство недоступно или вернулось, служба или адаптер Yggdrasil, битый конфиг, крайний перебор, батарея, автопроверки замолчали, восстановлен exe, вышла новая версия. Рутинное «всё в порядке» не присылается. В каждом сообщении указано имя устройства.

### Linux-версия сейчас

Работает по прежней логике. Резервные пиры добавляются, только когда легли все основные, и убираются, как только оживёт любой основной. Регион поездки там — отдельный режим, в котором основные пиры не проверяются. Нет проверки «постоянно рвётся», стража, статистики и восстановления конфига. Обновление ищется в релизах GitHub, а их нет, поэтому обновляйся теми же командами, что и при установке.

## Установка

### Windows

**1. Скачай файлы.** Открой папку [`windows`](windows) в этом репозитории и скачай оттуда файлы. Чтобы скачать файл, кликни по нему, а потом на кнопку **Download raw file** (стрелка вниз справа над содержимым).

| Файл | Зачем |
|---|---|
| `ygg_watchdog.exe` | Сама программа: окно, проверки, значок в трее |
| `ygg_guard.exe` | Страж: его запускает Планировщик, он проверяет целостность программы |
| `cities.dat` | База городов, без неё не работает выбор города и сортировка по расстоянию |
| `notify.conf.example` | Пример настроек Telegram (нужен, только если хочешь уведомления) |

Остальные файлы в папке (`.cpp`, `.bat`, `.rc`, `.ico`, папки `gui` и `tests`) — исходники, сборка и тесты, для работы они не нужны.

**2. Положи их в одну постоянную папку**, например `C:\Tools\ygg-watchdog`. Не оставляй их в «Загрузках»: задача Планировщика запоминает путь к программе, и если потом переместить папку, проверки перестанут запускаться (значок в трее это заметит и предложит восстановить задачу).

**3. Дважды кликни `ygg_watchdog.exe`.** Windows попросит права администратора, соглашайся. Откроется окно.

**4. Вкладка «Управление» [N] → «Установить».** Это создаст задачу в Планировщике Windows. Программа будет проверять связь каждые 3 минуты в фоне, даже когда никто не вошёл в систему, и сразу после пробуждения. Больше ничего делать не нужно.

Если программу блокирует Защитник Windows, добавь папку программы в исключения (Безопасность Windows → Защита от вирусов и угроз → Управление настройками → Исключения).

**Собрать самому** (если поменял код): скачай весь репозиторий (зелёная кнопка **Code → Download ZIP**), открой папку `windows` и запусти `run_ygg_watchdog.bat`. Он соберёт `ygg_watchdog.exe` и `ygg_guard.exe`. Нужен компилятор: [MinGW-w64](https://winlibs.com/) или Visual Studio с компонентом «Разработка классических приложений на C++». Тесты: `tests\run_tests.bat`.

Подробно про окно, файлы и команды: [windows/README_WINDOWS.md](windows/README_WINDOWS.md)

### Linux

Нужны Python 3, systemd, git и установленный Yggdrasil.

**Установка** — скопируй и выполни целиком:

```bash
git clone https://github.com/Yozmor/ygg-watchdog.git /tmp/ygg-src
mkdir -p ~/ygg-watchdog
cp -r /tmp/ygg-src/linux/. ~/ygg-watchdog/
rm -rf /tmp/ygg-src
cd ~/ygg-watchdog
sudo ./install.sh
```

Что происходит по шагам:
1. репозиторий скачивается во временную папку `/tmp/ygg-src`;
2. создаётся папка программы `~/ygg-watchdog`;
3. туда копируются файлы из папки `linux` (именно файлы, без лишней вложенной папки);
4. временная папка удаляется;
5. `install.sh` включает автопроверку каждые 3 минуты и добавляет команду `ygg-watchdog` для меню.

Программа живёт и работает в `~/ygg-watchdog`. Не клонируй репозиторий прямо в `~/ygg-watchdog`: там должна лежать сама программа, а не весь репозиторий.

**Обновление** — те же команды. Новые файлы заменят старые, а твои `notify.conf`, `state.json` и логи останутся: в репозитории их нет, поэтому они не перезаписываются.

**Проверка и работа:**

```bash
ygg-watchdog                                    # меню
sudo python3 -B ~/ygg-watchdog/selftest.py      # самопроверка, все пункты должны быть OK
tail -f ~/ygg-watchdog/watchdog.log             # лог
```

**Удаление:**

```bash
cd ~/ygg-watchdog && sudo ./install.sh --remove   # выключить автопроверку
sudo rm -rf ~/ygg-watchdog                        # удалить файлы
```

Подробно: [linux/README_LINUX.md](linux/README_LINUX.md)

## Регионы поиска

Программе нужно знать, где искать замену пирам. На Windows она идёт по очереди и не проверяет одну страну дважды:

1. **Выход трафика** — страна, которую видит интернет: программа смотрит свой публичный IP через GeoIP. Если трафик идёт через VPN, это страна VPN. Значение кэшируется на час.
2. **Регион поездки** — страна и город, заданные вручную на время поездки. Основные пиры при этом работают как обычно, регион влияет только на поиск замены.
3. **Домашний регион** — постоянный запасной вариант, задаётся вручную.
4. **Страна основных пиров** — если ничего из перечисленного не задано и GeoIP недоступен.

Если задан город, первыми проверяются пиры, ближайшие к нему.

На Windows всё это задаётся на вкладке «Регион» окна или командами `add-region <страна> [город]`, `remove-region`, `set-home-region <страна> [город]`. На Linux:

```bash
sudo python3 watchdog_daemon.py list-countries
sudo python3 watchdog_daemon.py set-home-region russia
```

## Мониторинг устройств

Можно добавить несколько своих компьютеров (телефон намеренно не поддерживается) для проверки доступности внутри сети Yggdrasil. Проверяются они только после того, как связь через пиры подтверждена: если её нет, проверять устройства бессмысленно. На Windows все устройства проверяются одновременно. Если пинг закрыт, проверяются порты 445, 3389 и 22.

На Windows — вкладка «Устройства» или команды `add-device` / `list-devices` / `remove-device`. На Linux:

```bash
sudo python3 watchdog_daemon.py add-device ThinkPad 200:1234:abcd::1
sudo python3 watchdog_daemon.py list-devices
sudo python3 watchdog_daemon.py remove-device ThinkPad
```

## VPN (продвинутый режим)

По умолчанию программа ничего в VPN не настраивает, а только предупреждает, если похоже, что проблема в нём. Если хочешь, чтобы она сама перезапускала VPN при сбое, один раз одобри свой скрипт перезапуска:

```bash
# Linux
sudo python3 watchdog_daemon.py approve-vpn-command /путь/к/своему/restart-vpn.sh
```

На Windows — «Управление» → «Выбрать скрипт…» (или команда `approve-vpn-command <путь>`).

Перед каждым запуском скрипта программа пересчитывает его SHA-256 и сравнивает с тем, что был при одобрении. Если скрипт изменился хоть на байт, запуск откажется, пока его не одобрят снова. Снять одобрение: `clear-vpn-command`.

## Обновления

Релизов нет: всё лежит прямо в репозитории.

- **Windows.** Раз в сутки программа читает `CURRENT_VERSION` в `windows/ygg_watchdog.cpp` на GitHub. Если версия там новее, присылает уведомление и сама ничего не ставит. Обновление ставится кнопкой «Управление» → «Установить» (или командой `apply-update`). Программа скачивает `windows/ygg_watchdog.exe`, сверяет его отпечаток с репозиторием, а старую версию сохраняет как `ygg_watchdog.exe.backup`.
- **Linux.** Пока обновляйся теми же командами, что и при установке.

## Уведомления в Telegram

1. Создай бота через `@BotFather` (`/newbot`) и получи токен.
2. Напиши своему боту любое сообщение.
3. Открой `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найди число в `"chat":{"id": ...}`.
4. Переименуй `notify.conf.example` в `notify.conf` и впиши:

```
BOT_TOKEN=123456:ABC-DEF...
CHAT_ID=987654321
```

На Windows то же самое можно сделать в окне: «Управление» → поля Telegram → «Сохранить», потом «Проверить». Если Telegram открывается только через локальный прокси, впиши его в `PROXY=адрес:порт` в том же файле: задача Планировщика работает от SYSTEM и системный прокси пользователя не видит.

Канал односторонний: программа только отправляет сообщения и команд из Telegram не принимает. Без `notify.conf` уведомления просто выключены, всё остальное работает.

## Команды без меню (Linux)

```bash
cd ~/ygg-watchdog
sudo python3 watchdog_daemon.py tick                          # одна проверка
sudo python3 watchdog_daemon.py status                        # статус
sudo python3 watchdog_daemon.py list-countries                # список стран
sudo python3 watchdog_daemon.py list-cities russia            # города страны
sudo python3 watchdog_daemon.py add-region russia Vladivostok # включить регион
sudo python3 watchdog_daemon.py remove-region                 # выключить регион
sudo python3 watchdog_daemon.py set-home-region russia        # домашний регион
sudo python3 watchdog_daemon.py add-main-peer tls://host:port # добавить основной пир
sudo python3 watchdog_daemon.py add-device ThinkPad 200::1    # устройство для мониторинга
sudo python3 watchdog_daemon.py approve-vpn-command ./vpn.sh  # одобрить VPN-скрипт
sudo python3 watchdog_daemon.py restart-yggdrasil-delayed 15  # перезапуск через 15 с
```

Команды Windows-версии — в [windows/README_WINDOWS.md](windows/README_WINDOWS.md#команды-для-планировщика-окна-и-консоли).

## Состав репозитория

```
windows/    C++-версия: ygg_watchdog.exe и ygg_guard.exe (готовые программы),
            ygg_watchdog.cpp (логика и команды), ygg_guard.cpp (страж),
            gui/ (окно, значок в трее, общие с панелью ygg-control заголовки),
            tests/ (проверки без сети), run_ygg_watchdog.bat (сборка), иконка

            peer_database.py, geoip.py, device_monitor.py, battery.py, vpn_hook.py,
            auto_update.py, selftest.py, systemd-таймер, install.sh
assets/     картинки для README
```

В обеих папках лежат `cities.dat` (база городов GeoNames с координатами) и `notify.conf.example` (пример настроек Telegram).
