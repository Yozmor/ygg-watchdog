# Yggdrasil Watchdog (Linux) - инструкция

## Что это

Автоматика, которая следит за пирами Yggdrasil и сама чинит связь при
проблемах. Плюс - ручное меню для управления регионами и основными
пирами, когда нужно вмешаться самому.

## Что работает автоматически, без твоего участия

Раз в 3 минуты systemd-таймер запускает проверку (`tick`):

- Если все основные пиры легли - ищет замену того же региона, что
  основные, проверяет настоящим рукопожатием, добавляет как резервного
- Как только основной снова жив - резервные убираются
- Если включён региональный режим - следит за региональными пирами
  вместо основных (полностью игнорирует основные, пока регион активен)
- Если пропал интернет вообще (не только пиры) - не тратит время на
  бессмысленный поиск, ждёт восстановления и сообщает об этом в лог

Проверить, что таймер жив:
```bash
systemctl status ygg-watchdog-tick.timer
systemctl list-timers ygg-watchdog-tick.timer
```

## Установка

```bash
git clone https://github.com/Yozmor/ygg-watchdog.git
cd ygg-watchdog/linux
sudo ./install.sh
```

Установщик скопирует программу в `/opt/ygg-watchdog`, настроит и включит systemd-таймер и добавит команду `ygg-watchdog`. Повторный запуск обновляет программу, `notify.conf`, состояние и логи сохраняются. Удаление: `sudo ./install.sh --remove`.

## Как запустить панель управления вручную

```bash
ygg-watchdog
```

(или `sudo python3 /opt/ygg-watchdog/watchdog_daemon.py menu`)

Появится меню:

```
================================================
        YGG WATCHDOG
================================================

  1 - Проверить сейчас (tick)
  2 - Показать статус
  3 - Добавить регион (страна + город)
  4 - Убрать региональный режим
  5 - Показать основные пиры
  6 - Добавить основной пир
  7 - Удалить основной пир
  8 - Перезапустить Yggdrasil СЕЙЧАС (обрывает сессии по Yggdrasil!)
  9 - Перезапустить Yggdrasil С ЗАДЕРЖКОЙ (безопасно при SSH по Yggdrasil)
  0 - Выход
```

### Пункт 1 - Проверить сейчас
То же самое, что делает таймер каждые 3 минуты, но сразу, не дожидаясь.
Полезно, чтобы проверить эффект сразу после ручной правки.

### Пункт 2 - Статус
Показывает: путь к конфигу, режим (normal/regional), список основных
пиров, список резервных (если есть), список региональных (если есть),
сколько событий скопилось в очереди уведомлений.

### Пункт 3 - Добавить регион
Спрашивает страну и город пошагово:
1. Покажет список стран (с GitHub, живой список) - вводишь номер
2. Покажет список городов именно этой страны (из базы GeoNames,
   с реальными координатами) - вводишь номер, или просто Enter, если
   нужен пир из любого города страны
3. Запустит поиск **в фоне** (отдельный процесс) - панель сразу
   возвращает управление, не ждёт. Настоящая проверка (рукопожатие)
   может занять от нескольких секунд до пары минут в зависимости от
   числа кандидатов.

Пока региональный режим активен - основные пиры полностью
игнорируются (это осознанное правило, не баг). Можно вызывать пункт 3
несколько раз подряд, чтобы добавить сразу несколько регионов -
предыдущие не потеряются.

Прогресс фонового поиска смотри в логе (см. ниже).

### Пункт 4 - Убрать региональный режим
Снимает **все** региональные пиры разом, возвращает обычный режим
слежения за основными.

### Пункты 5-7 - Основные пиры
- **5**: показывает список из `yggdrasil.conf`
- **6**: добавляет новый URI прямо в конфиг (спросит адрес)
- **7**: покажет список и попросит номер для удаления

**Важно**: правки конфига вступают в силу только после перезапуска
службы (пункты 8/9) - Yggdrasil читает конфиг один раз при старте.

### Пункты 8-9 - Перезапуск службы
- **8** - сразу. Если ты подключён к серверу через сам Yggdrasil
  (например SSH по Yggdrasil-адресу) - твоя же сессия оборвётся в
  процессе.
- **9** - с задержкой (по умолчанию 10 секунд, можно другую). Команда
  уходит по ещё живому каналу, а сам перезапуск происходит через
  несколько секунд - успеваешь отключиться/переключиться на другой
  канал до того, как соединение прервётся.

**Используй пункт 9, если не уверен, как именно сейчас подключён.**

## Уведомления в Telegram

Программа умеет присылать push-уведомления в Telegram на телефон в
трёх случаях:

- **Все основные пиры легли, найден резервный** - в сообщении будет
  указано, какие именно основные пиры отвалились, и какой резервный
  добавлен взамен
- **Основные пиры снова живы** - какие резервные удалены
- **Пропадал интернет целиком** (не только Yggdrasil) - одно
  сообщение с обоими точными временами: когда пропал и когда появился

Рутинные проверки ("всё в порядке, без изменений") в Telegram **не**
шлются - только реальные события, чтобы не спамить.

### Настройка (один раз)

1. Открой `@BotFather` в Telegram, отправь `/newbot`, следуй
   инструкциям - получишь токен вида `123456:ABC-DEF...`
2. Напиши что-нибудь своему новому боту (любое сообщение)
3. Открой в браузере:
   `https://api.telegram.org/bot<ТВОЙ_ТОКЕН>/getUpdates`
4. В ответе найди число в поле `"chat":{"id": ЭТО_ЧИСЛО}`
5. Переименуй `notify.conf.example` в `notify.conf` (та же папка, что
   `watchdog_daemon.py`), впиши токен и chat_id:
   ```
   BOT_TOKEN=123456:ABC-DEF...
   CHAT_ID=987654321
   ```

Если файла `notify.conf` нет вообще, или в нём не хватает одного из
полей - уведомления просто молча выключены, ничего не ломается и не
падает с ошибкой.

**Если у тебя два устройства (например Linux-сервер и Windows-ноутбук) шлют
уведомления в одного и того же бота** - в каждом сообщении автоматически
указывается имя устройства-отправителя (реальное имя хоста), чтобы
не путать, откуда пришло.

## Логи

```bash
tail -f /opt/ygg-watchdog/watchdog.log
```

По умолчанию видны только осмысленные события (что произошло на
каждой проверке, включая "без изменений", а не только аномалии). Для
подробностей (что именно проверялось, почему принято решение):

```bash
sudo python3 /opt/ygg-watchdog/watchdog_daemon.py -v tick
```

Логи старше 14 дней автоматически подчищаются, файл не растёт
бесконечно.

## Проверка после переноса на новый сервер / после обновления файлов

```bash
sudo python3 /opt/ygg-watchdog/selftest.py
```

Пройдёт ряд проверок: файлы на месте, синтаксис, реальный запрос к
GitHub, реальная проверка базы городов (расстояние Москва-Владивосток),
реальное рукопожатие с живым кандидатом, статус таймера. Все пункты
должны быть `OK`.

## Файлы проекта

| Файл | Назначение |
|---|---|
| `peer_database.py` | GitHub-пиры, база городов с координатами, настоящее рукопожатие |
| `watchdog_core.py` | Логика принятия решений, состояние, правка конфига, перезапуск службы |
| `watchdog_daemon.py` | Командная строка + интерактивное меню |
| `cities.dat` | База городов GeoNames (обязателен, без него региональный поиск по координатам не работает) |
| `notify.conf` | Токен/chat_id для уведомлений в Telegram (необязателен - без него уведомления просто выключены) |
| `selftest.py` | Самопроверка после установки/переноса/обновления |
| `ygg-watchdog-tick.service` / `.timer` | systemd-таймер, автоматическая проверка каждые 3 минуты |

## Команды напрямую (без меню), если нужна автоматизация/скрипты

```bash
cd /opt/ygg-watchdog
sudo python3 watchdog_daemon.py tick                          # один цикл проверки
sudo python3 watchdog_daemon.py status                        # статус
sudo python3 watchdog_daemon.py list-countries                # список стран
sudo python3 watchdog_daemon.py list-cities russia            # города страны (номер или slug)
sudo python3 watchdog_daemon.py add-region russia Vladivostok # регион напрямую (без меню)
sudo python3 watchdog_daemon.py remove-region
sudo python3 watchdog_daemon.py list-main-peers
sudo python3 watchdog_daemon.py add-main-peer tls://host:port
sudo python3 watchdog_daemon.py remove-main-peer 2
sudo python3 watchdog_daemon.py restart-yggdrasil
sudo python3 watchdog_daemon.py restart-yggdrasil-delayed 15
```

## Про графический ярлык (двойной клик)

Пробовали - не завелось на этой конкретной установке (`Terminal=true`
в `.desktop`-файле не находит терминал, хотя `xfce4-terminal`
формально есть в системе - похоже, GNOME его не видит как
зарегистрированный терминал по умолчанию). Решили не тратить на это
время - панель полностью рабочая через обычный терминал, этого
достаточно.
